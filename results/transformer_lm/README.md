# Transformer-LM Results

Reference histories and plots for the LayerNorm / GPT-2 validation experiment.

## Layout

- `wikitext_small_gpt2/`: 4-block, `d_model=256` GPT-2-style model on WikiText.
- `openweb_gpt2/`: 12-block, `d_model=768` GPT-2-style model on OpenWebText.
- `summary.json`: compact statistics generated by `scripts/replot_transformer_lm.py`.

Each dataset directory mirrors the collaborator-supplied result structure:

- `multiseed/conv_histories.json`: plain SGD histories. The directory/file names
  are inherited from the original ConvNet script, but the contents are
  Transformer attention-block diagnostics.
- `sgdm/sgdm_histories.json`: SGD and SGDM histories.
- `adam/adam_histories.json`: SGD, coupled-WD Adam, and decoupled-WD AdamW
  histories.

The paper uses the aggregate figure generated by:

```bash
python scripts/replot_transformer_lm.py \
  --results_dir results \
  --out_path ../paper/figures/fig_transformer_lm.png
```

The original cluster job wrappers were intentionally not copied into the public
supplement because they contained hardcoded personal paths, SLURM account names,
and private W&B setup.
