# Supplementary Material

Code for the paper **When Does Scale-Invariant Optimization Become Unstable? An Exact Discrete-Time Law with Weight Decay**.

## Overview

- `src/`: Reusable theory, diagnostics, model, and training code.
- `scripts/`: Canonical entry points for reproducing all paper experiments.
- `results/`: Pre-computed reference outputs (summaries and figures).

## Install

```bash
pip install -r requirements.txt
```

## Reproducing All Paper Figures

The fastest path to regenerating every figure in the paper:

```bash
# From supplementary_material/ directory:
python scripts/generate_paper_figures.py \
  --results_dir results --out_dir results/paper_figures

# Copy to paper figures directory:
cp results/paper_figures/fig_*.png ../paper/figures/
```

This reads pre-computed results from `results/` and generates all 15 paper figures.
Figures that need no saved data (exact maps, spiral source, anisotropic) are re-simulated on the fly.

**Note**: Two figures (`fig_mlp_multiseed.png`, `fig_conv_multiseed.png`) require full history files that are generated by `run_multiseed.py` but are too large to include in this release. Run `run_multiseed.py` first to produce them, or use the pre-generated PNGs in `results/multiseed/`.

## Running Individual Experiments

### Exact theory and controlled simulations (CPU, seconds)

```bash
python scripts/run_exact_map.py --out_dir results/exact_map
python scripts/run_spiral_source.py --out_dir results/spiral
python scripts/run_anisotropic.py --out_dir results/anisotropic
```

### Core neural experiments (GPU recommended)

```bash
export DATA_ROOT=/path/to/data   # CIFAR-10, MNIST

# Multi-seed BN-MLP, BN-ConvNet, and target-B sweep
python scripts/run_multiseed.py \
  --out_dir results/multiseed --data_root "$DATA_ROOT" --device cuda:0

# Near-critical controls (MNIST)
python scripts/run_mnist_criticality.py \
  --out_dir results/mnist_criticality --data_root "$DATA_ROOT" --device cuda:0

# Minibatch robustness sweep
python scripts/run_minibatch_sweep.py \
  --out_dir results/minibatch --data_root "$DATA_ROOT" --device cuda:0

# SGDM augmented-state study (radial pump, exponent scan)
python scripts/run_sgdm.py \
  --out_dir results/sgdm --data_root "$DATA_ROOT" --device cuda:0

# SGD / Adam / AdamW comparison
python scripts/run_adam.py \
  --out_dir results/adam --data_root "$DATA_ROOT" --device cuda:0

# Adam epsilon-continuity study
python scripts/run_adam_epsilon.py \
  --out_dir results/adam_epsilon --data_root "$DATA_ROOT" --device cuda:0
```

### Regenerate derived figures from saved histories

```bash
python scripts/replot_beyond_sgd.py \
  --results_dir results --out_dir results/beyond_sgd

python scripts/replot_figures.py \
  --results_dir results --out_dir results

python scripts/replot_optimizer_mechanisms.py \
  --results_dir results --out_dir results/optimizer_mechanisms

python scripts/replot_adam_epsilon.py \
  --histories_path results/adam_epsilon/adam_epsilon_histories.json \
  --out_dir results/adam_epsilon
```
