# Supplementary Material

Code release for **Feedback and Instability in Scale-Invariant Optimization: An Exact Discrete-Time Law with Weight Decay** (NeurIPS 2026 submission).

## Overview

- `src/` — Reusable theory, diagnostics, model, and training code.
- `scripts/` — Canonical entry points for reproducing all paper experiments.
- `results/` — Pre-computed reference outputs (summaries and figures).

All experiments use 5 seeds (42--46) with mean +/- std error bars.

## Install

```bash
pip install -r requirements.txt
```

Neural-network experiments benefit from CUDA. Exact-map, spiral-source, and anisotropic scripts run on CPU in seconds.

## Reproducing All Paper Figures

The fastest path to regenerating every figure in the paper:

```bash
# From supplementary_material/ directory:
python scripts/generate_paper_figures.py \
  --results_dir results --out_dir results/paper_figures

# Copy to paper figures directory:
cp results/paper_figures/fig_*.png ../paper/figures/
```

This reads pre-computed results from `results/` and generates all 15 paper figures.
Figures that need no saved data (exact maps, spiral source, anisotropic) are re-simulated on the fly.

**Note**: Two figures (`fig_mlp_multiseed.png`, `fig_conv_multiseed.png`) require full history files that are generated by `run_multiseed.py` but are too large to include in this release. Run `run_multiseed.py` first to produce them, or use the pre-generated PNGs in `results/multiseed/`.

## Running Individual Experiments

All commands below are run from the `supplementary_material/` directory.

### Exact theory and controlled simulations (CPU, seconds)

```bash
python scripts/run_exact_map.py --out_dir results/exact_map
python scripts/run_spiral_source.py --out_dir results/spiral
python scripts/run_anisotropic.py --out_dir results/anisotropic
```

### Core neural experiments (GPU recommended)

```bash
export DATA_ROOT=/path/to/data   # CIFAR-10, MNIST

# Multi-seed BN-MLP, BN-ConvNet, and target-B sweep
python scripts/run_multiseed.py \
  --out_dir results/multiseed --data_root "$DATA_ROOT" --device cuda:0

# Near-critical controls (MNIST)
python scripts/run_mnist_criticality.py \
  --out_dir results/mnist_criticality --data_root "$DATA_ROOT" --device cuda:0

# Minibatch robustness sweep
python scripts/run_minibatch_sweep.py \
  --out_dir results/minibatch --data_root "$DATA_ROOT" --device cuda:0

# SGDM augmented-state study (radial pump, exponent scan)
python scripts/run_sgdm.py \
  --out_dir results/sgdm --data_root "$DATA_ROOT" --device cuda:0

# SGD / Adam / AdamW comparison
python scripts/run_adam.py \
  --out_dir results/adam --data_root "$DATA_ROOT" --device cuda:0

# Adam epsilon-continuity study
python scripts/run_adam_epsilon.py \
  --out_dir results/adam_epsilon --data_root "$DATA_ROOT" --device cuda:0
```

### Regenerate derived figures from saved histories

```bash
python scripts/replot_beyond_sgd.py \
  --results_dir results --out_dir results/beyond_sgd

python scripts/replot_figures.py \
  --results_dir results --out_dir results

python scripts/replot_optimizer_mechanisms.py \
  --results_dir results --out_dir results/optimizer_mechanisms

python scripts/replot_adam_epsilon.py \
  --histories_path results/adam_epsilon/adam_epsilon_histories.json \
  --out_dir results/adam_epsilon
```

## Script Guide

| Script | Description | Paper figures |
|--------|-------------|---------------|
| `run_exact_map.py` | Exact 2D isotropic map (3 schedules) | fig_schedule_control, fig_schedule_control_compact |
| `run_spiral_source.py` | Fixed-point instability, long-run recurrence | fig_spiral, fig_iso_longrun |
| `run_multiseed.py` | BN-MLP, BN-ConvNet, target-B sweep | fig_mlp_multiseed, fig_conv_multiseed, fig_neural_transitions, fig_target_b_multiseed |
| `run_mnist_criticality.py` | Near-critical MNIST controls | fig_extended_criticality_controls |
| `run_minibatch_sweep.py` | Batch-size robustness | fig_minibatch |
| `run_sgdm.py` | SGDM radial pump + exponent scan | fig_sgdm_radial_pump, fig_sgdm_radial_pump_compact |
| `run_adam.py` | SGD/Adam/AdamW comparison | fig_beyond_sgd, fig_ratio_residual_spectrum, fig_layerwise |
| `run_adam_epsilon.py` | Adam epsilon-continuity | fig_adam_epsilon_residual |
| `run_anisotropic.py` | Anisotropic normalized-linear sweeps | fig_anisotropic_phi |
| `replot_beyond_sgd.py` | Combined optimizer comparison from saved histories | fig_beyond_sgd, fig_ratio_residual_spectrum, fig_layerwise |
| `replot_optimizer_mechanisms.py` | Exponent-structure comparison | fig_optimizer_exponent_scan |
| `generate_paper_figures.py` | **Unified script**: regenerate all paper figures | all |

The compact main-text figures (`fig_neural_transitions`, `fig_schedule_control_compact`, `fig_sgdm_radial_pump_compact`) are derived by cropping/stacking the full-resolution figures; see the `paper/figures/` directory or the figure-generation section of the main paper.

## Results Layout

| Directory | Contents |
|-----------|----------|
| `exact_map/` | Exact-map trajectories, schedule controls |
| `spiral/` | Spiral-source verification, long-run dynamics |
| `multiseed/` | MLP/ConvNet/target-B summaries and figures |
| `mnist_criticality/` | Near-critical control histories |
| `minibatch/` | Batch-size sweep histories |
| `sgdm/` | SGDM histories (87 MB), radial pump figures |
| `adam/` | SGD/Adam/AdamW histories (47 MB) |
| `adam_epsilon/` | Epsilon-continuity histories (124 MB) |
| `anisotropic/` | Condition-number sweep |
| `beyond_sgd/` | Combined optimizer figures |
| `optimizer_mechanisms/` | Exponent-scan figure |

**Large files**: Three history JSONs (sgdm: 87 MB, adam: 47 MB, adam_epsilon: 124 MB) exceed GitHub's 100 MB single-file limit. They are generated by the `run_*.py` scripts and are needed only for replotting derived figures. The pre-generated PNGs in each results subdirectory can be used directly.

## Notes

- The central diagnostic is the schedule factor $B_t$, computed from the exact factorization appropriate to each optimizer.
- For SGD with coupled weight decay, the ratio residual is at machine precision (~10^-6). For SGDM/Adam it is ~10^-2; for AdamW ~10^-1.
- All random seeds use `torch.Generator(device='cpu')` for cross-platform reproducibility.
